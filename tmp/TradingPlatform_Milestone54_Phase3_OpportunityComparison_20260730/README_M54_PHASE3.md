# Milestone 54 Phase 3 — Opportunity Comparison

Adds governed multi-opportunity comparison and exclusive preferred-opportunity designation to the canonical Institutional Opportunity Workspace.

## Features
- Select and compare up to four opportunities.
- Side-by-side AI, trend, transition, dealer, institutional, probability, risk/reward, Greeks, liquidity, and spread evidence.
- Explicit mixed-scanner-run and mixed-snapshot provenance diagnostics.
- Exclusive preferred opportunity per scanner-run/snapshot cohort.
- Optimistic version enforcement for preferred designation.
- Append-only audit events when preference is assigned or superseded.

No new database migration is required beyond `m54_001` from Phase 1.
